# Segmented

A compact switch between 2–5 views or filters of the same content.

**Markup.** `<div class="rt-seg" role="group" aria-label="…">` with `<button aria-pressed="true|false">`.

- For views and filters, not for navigation between pages (use the sidebar) or for settings (use a toggle).
- Labels are 1–2 words. Four options maximum on mobile.
- Motion: the selected surface slides between options with the indicator spring (shared layout). See Motion.
